              Distribution Key Selection Justification
              

                LocationKey was selected over
                DateKey and
                CharacteristicKey.
                Cardinality (842 sites) provides optimal hash distribution across 32 shards. It co-locates site timeseries data, avoiding network shuffles during site aggregation queries.
              

            


            

              Data Skew & Scale Crossover Point
              

                At ≤ 100K rows, centralised PostgreSQL is slightly faster (82ms vs 114ms) due to coordinator two-phase commit overhead.
                At 4.21M rows, Citus achieves a 7.42× speedup (1,840ms vs 248ms) via parallel shard execution.

OLAP Multidimensional Cube Operations Simulator

CUBE / ROLLUP / DRILL / SLICE

Simulate enterprise OLAP operations across the 3 core hierarchies: Time, Geography, and Water Parameter Groups.

OPERATION: ROLL-UP (Month → Year) PostgreSQL / SQL-99 
SELECT 
    d.Year,
    c.ParameterGroup,
    COUNT(*) AS SampleCount,
    ROUND(AVG(f.ResultMeasureValue)::numeric, 2) AS MeanResult,
    SUM(f.ExceedanceFlag) AS ExceedanceCount
FROM FactWaterQualityResult f
JOIN DimDate d ON f.DateKey = d.DateKey
JOIN DimCharacteristic c ON f.CharacteristicKey = c.CharacteristicKey
GROUP BY ROLLUP(d.Year, c.ParameterGroup)
ORDER BY d.Year NULLS LAST;

Distributed Citus vs Centralised PostgreSQL Performance Benchmarks

Horizontal Scale-Out Experiment

Empirical query latency comparison across 100K, 500K, 1M, 2M, and the complete 4.21M row dataset on 8 worker nodes.

Distribution Key Selection Justification

LocationKey was selected over DateKey and CharacteristicKey. Cardinality (842 sites) provides optimal hash distribution across 32 shards. It co-locates site timeseries data, avoiding network shuffles during site aggregation queries.

Data Skew & Scale Crossover Point

At ≤ 100K rows, centralized PostgreSQL is slightly faster (82ms vs 114ms) due to coordinator two-phase commit overhead. At 4.21M rows, Citus achieves a 7.42× speedup (1,840ms vs 248ms) via parallel shard execution.
